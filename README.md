# RealTime-TSR

基于 `YOLOv5 + PyQt5 + OpenCV` 的实时交通标志识别项目。

这个项目将本地训练好的交通标志检测模型接入桌面图形界面，实现了视频文件实时检测、检测框可视化、检测摘要展示和历史日志记录，适合作为课程设计、项目展示或复试项目。

## 项目简介

项目当前主线是：

- 使用本地 `YOLOv5` 模型进行交通标志检测
- 使用 `PyQt5` 搭建桌面 GUI
- 使用 `OpenCV` 读取视频并逐帧推理
- 在界面中同步展示检测画面、当前结果、日志和历史记录

当前推荐演示入口：

```bash
python gui.py
```

## 功能特性

- 支持本地视频文件导入
- 支持逐帧实时检测与结果可视化
- 支持在画面上绘制检测框和类别置信度
- 支持展示当前帧检测摘要
- 支持记录运行日志和历史检测结果
- 支持播放、暂停、进度拖动等基本交互

## 技术栈

- Python
- YOLOv5
- PyTorch
- OpenCV
- PyQt5

## 核心模块说明

### `gui.py`

当前主界面文件，负责：

- 打开视频
- 控制播放和暂停
- 显示推理后的图像
- 展示当前帧检测结果
- 记录日志和历史信息

### `detector.py`

检测封装模块，负责：

- 加载本地 YOLOv5 模型
- 设置推理阈值
- 对单帧图像进行检测
- 输出结构化检测结果和用于 GUI 展示的摘要文本

### `yolov5_local/`

保留了本地 YOLOv5 训练与推理相关代码，方便继续训练、测试或调整模型。

## 运行方式

### 1. 安装依赖

建议使用 Python 虚拟环境。

常见依赖包括：

```bash
pip install torch opencv-python PyQt5
```

如果你还要完整运行 `yolov5_local/` 中的训练或验证流程，可以再参考其中的依赖配置。

### 2. 启动界面

```bash
python gui.py
```

### 3. 使用流程

1. 启动程序
2. 点击“打开视频”
3. 选择 `test/` 目录中的示例视频，或自己的测试视频
4. 程序开始逐帧检测
5. 右侧查看检测摘要、日志和历史记录

## 数据与模型说明
